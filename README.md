# Фокус для компьютера (Windows и Mac)

Блок видео во всех браузерах, ночной режим (соцсети и маркетплейсы), свои правила для сайтов и программ.
Ослабить что-либо можно только одноразовым кодом Google Authenticator владельца ключа.
Обновляется сам с GitHub Releases.

## Установка
- **Windows:** скачать `Fokus-Setup.exe` из последнего релиза и запустить («Подробнее» → «Выполнить в любом случае», потом «Да»). Мастер установки ставит «Фокус» в «Пуск» и на рабочий стол.
- **Mac:** скачать `Fokus-Mac.pkg` и открыть. Если Mac скажет, что не может проверить разработчика: «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть». «Фокус» появится в «Программах» и в Launchpad.
- Запасной способ для Mac, в «Терминале»:
  `curl -fsSL https://github.com/gradinarnick/Fokus-Desktop/releases/latest/download/install-mac.sh | bash`

Окно «Фокуса»: значок «Фокус» (в «Пуске», на рабочем столе, в «Программах» на Mac) (http://127.0.0.1:47890/).
