# Фокус для компьютера (Windows и Mac)

Блок видео во всех браузерах, ночной режим (соцсети и маркетплейсы), свои правила для сайтов и программ.
Ослабить что-либо можно только одноразовым кодом Google Authenticator владельца ключа.
Обновляется сам с GitHub Releases.

## Установка
- **Windows:** скачать `fokus-windows.exe` из последнего релиза и запустить («Подробнее» → «Выполнить в любом случае», потом «Да»).
- **Mac:** в «Терминале»:
  `curl -fsSL https://github.com/gradinarnick/Fokus-Desktop/releases/latest/download/install-mac.sh | bash`

Окно «Фокуса»: значок «Фокус» на рабочем столе (http://127.0.0.1:47890/).
